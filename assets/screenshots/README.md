# Screenshot placeholders

Add the application's screenshots to this folder and use the following filenames in the main README:

- `login.png` — Login screen
- `search.png` — Search / holiday planning screen
- `results.png` — Recommended destinations screen
- `favourites.png` — Favourites screen
- `currency-converter.png` — Currency Converter popup

These placeholders are intentional because the project was provided without output screenshots.
